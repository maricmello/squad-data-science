## Checagens já feitas para mitigar o risco de vazamento (sem dicionário oficial)

Como não é possível confirmar a definição exata de cada variável, os seguintes testes independentes foram feitos para reduzir (não eliminar) o risco de vazamento:

- **Correlação `ticket × frequência` vs. `gasto_mensal`**: 0,17 — se `gasto_mensal` fosse simplesmente `ticket médio × frequência` do mesmo período (vazamento direto óbvio), essa correlação seria próxima de 1,0. Não é o caso.
- **VIF (colinearidade) entre todas as features**: ≈ 1,0 para todas — nenhuma feature é combinação linear de outra, o que também tornaria improvável (embora não impossível) uma feature ser derivada diretamente de outra de forma oculta.
- **R² máximo obtido (~0,53–0,58)**: um vazamento direto e forte da target normalmente produz R² muito próximo de 1,0 (a "informação perfeita" vaza para o modelo). O R² moderado observado é mais consistente com features genuinamente preditivas, mas parciais, do que com vazamento.

Nenhuma dessas checagens substitui a confirmação da fonte de dados — elas apenas tornam um vazamento grosseiro menos provável.
